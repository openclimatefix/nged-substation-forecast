# Fixed-pipeline recipe feature inventory

This registry supports the [forecast and lean-input study](fixed-pipeline-lean-features.md).
It lists configured recipes, including conditional solar steps and the best-point recipe;
inclusion here does not mean a recipe was fitted. The study's results and execution decisions
identify which comparisons ran. The table is copied from the committed inventory script's output.

Recipe inputs precede encoding. Padding width excludes the numeric site identifier;
trained counts and order include it when requested by a pooled recipe.
The pooled site identifier is Float32 numeric.
Lists come from the fitter's equal-padding preparation on two synthetic rows.
No data were read and no model was fitted. Empty added/removed cells mean none.

The component migration must have passed its full readiness checks before either component
treatment is built. Source reconstruction supplies no weather or power data. Use new output
directories throughout; these commands describe reproduction and have not themselves been run
