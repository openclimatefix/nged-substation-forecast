# Differentiable physics: the network

**The summary of this theme is in progress.** The differentiable-physics series models Primary
substation demand from physical terms. This theme covers what the connections between Primary
substations add: power flowing along the interconnections between neighbouring Primary substations
when the network operator switches load from one to another, and a forecast of demand under the
normal running arrangement (NRA), with those transfers removed. The [Experiments](experiments.md)
page lists every experiment tried, with its verdict and a take-home message, and the
[Research plan](plan.md) lists what is planned next.
