# Differentiable physics: embedded generation

**The summary of this theme is in progress.** The differentiable-physics series builds models from
physical terms (demand, heating, solar) whose parameters are fitted to the power a Primary
substation draws. This theme covers the generation side of a Primary substation: whether the convex
model can read an MVA meter, find a flat unmetered generator where one exists and not invent one
where none does, represent an export-limited solar clip, and identify how much rooftop solar sits
behind each substation. The [Experiments](experiments.md) page lists every experiment tried, with
its verdict and a take-home message, and the [Research plan](plan.md) lists what is planned next.
