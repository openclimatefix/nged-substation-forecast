# Past-weather studies: which weather product best describes past solar and wind output

**This folder holds the scripts behind the pages under Studies > Past weather.** Each study scores
weather products against metered solar and wind output on the same rows, folds, and seeds, and the
published pages carry the design and the results. Every script's module docstring gives the command
that runs it.

**A script imports only from this folder, from `studies.*` (`packages/studies/`), and from the other
reviewed packages in `packages/*`.** The code that two study folders share lives in
`packages/studies/src/studies/`: the solar and wind common rows (`studies.solar_product_frames`,
`studies.wind_product_frames`, `studies.product_frames`), the PV dataset readers
(`studies.pv_dataset`), the fit runner (`studies.arm_runner`), the data paths (`studies.sources`),
and the trial-area box (`studies.trial_area`). Nothing in `src/` or in any package other than
`packages/studies` imports this folder.

**The folder holds 43 scripts for seven pages, so find a page's scripts in the table below rather than
by the folder name.** Tests of these scripts are in `packages/studies/tests/past_weather/`. The data
the scripts read and write is under `data/studies/`, which no version control tracks.

| `blend_products.py` | [Does blending weather products beat the best single weather product?](https://openclimatefix.github.io/nged-substation-forecast/studies/past-weather/blending/) | Asks whether a model shown several weather products at once beats the best single product, for solar and for wind, on the two weather-product studies' own rows, folds and seeds. Refits every published single-product arm and stops unless each reproduces the published per-row losses bit for bit. Blends each set of products from each product's plain columns and from its enriched columns (the neighbouring hours, CAMS's beam split, UKV's hour rebuilt from its snapshots; for wind, each speed at the hours around), and judges the enriched blends against the best single-product arm measured. Each set is blended four ways: XGBoost on every product's columns, XGBoost on the products' mean, a cross-fitted linear stack of the single-product predictions, and their equal-weight mean. Each XGBoost blend is scored against a climatology control whose extra columns are permuted within each site, month and hour of day, and a synthetic product carrying part of the target shows how small a gain the pipeline detects.
